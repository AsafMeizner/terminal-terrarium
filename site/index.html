    Run it in your terminal

    Every scene above is the real Python package, running in your browser through Pyodide. At home it needs Python 3.9+ and nothing else.

    pipx install git+https://github.com/AsafMeizner/terminal-terrarium

    Then try terrarium --all --shuffle --cycle 30 for screensaver mode, or terrarium --new my_scene to start your own scene.

    What this is

    A terrarium of procedural ASCII art: jellyfish, a lily bouquet, bonsai that grow, a tree's whole life in time-lapse, a city from dusk to dawn, a volcano, whales and more. Each scene rolls its own shapes, palettes and layout from the variation number, so no two runs are alike.

    Source, docs and a collection of the best terminal animations by others on GitHub. Inspired by @arimecoa's ASCII lily bouquet.
